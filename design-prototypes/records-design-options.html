⑦ 플랫 구조 (A + B)

중첩 탭 제거. 바텀탭(기록) → 본문. 끝. 서브탭(쓰기/달력)도, 상단 chip도 사라짐.

  • 달력 = 시트 모달: 날짜 네비 우측 ▦ 아이콘 → 아래에서 올라오는 시트. 선택하면 닫히며 이동. (사용 빈도 낮은 회고 도구의 제자리)
  • 고양이 = 필터: 오른쪽 상단 작은 pill ("고양이: 전체 ▼"). 탭으로 보이지 않음. 다묘 가정의 "지금은 이 녀석만" 니즈만 선택적 충족.
  • 기본은 카드 스택: 전체 요약 → 나비 / 치즈 / 루나 아코디언 카드. 첫 카드만 펼침, 탭해서 확장/수축.
장점 — 인지 부담 최저. "어디에 있지?" 없음. 하루 한 곳에서 모든 입력.
주의 — 달력이 "가려진 기능"이라 신규 유저가 못 찾을 수 있음. 첫 사용 시 툴팁/코치마크로 달력 위치 안내 필요.

※ 우측 상단 ▦ 아이콘으로 달력 시트를 열어보세요. 필터 pill도 드롭다운 됩니다.
